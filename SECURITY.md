# Security Policy

## Supported versions

PracticeMusic is under active development. Only the latest release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems. Email me@devs-des1re.com with:

- a description of the problem and its impact
- steps to reproduce it
- the PracticeMusic version and your operating system

You will get an acknowledgement within a few days. Once a fix is available it is released and the report is credited, unless you prefer to stay anonymous.

## Scope

PracticeMusic runs locally. The areas where a vulnerability matters most are the local IPC between the host and the audio engine, the handling of downloaded and imported media files, and the embedded browser pane.
